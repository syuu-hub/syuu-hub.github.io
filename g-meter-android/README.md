# Gメーター（Android アプリ）

公開ページ（https://syuu-hub.github.io/g-meter/）をアプリの中で開く外枠です。
画面や機能の更新は公開ページに反映すればアプリにも反映されます（APK の入れ直しは不要）。

ブラウザ版との違い（アプリ版でできること）
- 音声のお知らせを Android 本体の読み上げで鳴らす（アプリの中の画面では読み上げが使えないため）
- 振動、画面を点けたままにする、を Android 本体で行う
- CSV は共有メニューから保存先を選んで保存
- 記録はアプリ専用の場所に保存されるので、Chrome の履歴・サイトデータを消しても消えない
  （ブラウザ版の記録は引き継がれません）

## インストール
1. スマホで https://github.com/syuu-hub/syuu-hub.github.io/releases/tag/g-meter-apk を開き、`g-meter.apk` をダウンロード
2. 「提供元不明のアプリ」のインストールを許可してインストール
3. はじめて開く時は通信できる場所で。以降は圏外でも起動します

## 署名の鍵について
タクシーアナライザーと同じく、リポジトリの Secrets の鍵（`ANDROID_KEYSTORE_B64`・`ANDROID_KEY_PASS`）で署名します。
同じ鍵で署名している間は、新しい APK を上書きインストールしても記録は消えません。
