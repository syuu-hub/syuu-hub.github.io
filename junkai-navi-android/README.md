# 巡回ナビ（Android アプリ）

公開ページ（https://syuu-hub.github.io/junkai-navi/）をアプリの中で開く外枠です。
画面や機能の更新は公開ページに反映すればアプリにも反映されます（APK の入れ直しは不要）。

アプリ版でできること（ブラウザ版との違い）
- 音声案内を Android 本体の読み上げで鳴らす（アプリの中の画面ではブラウザの読み上げが使えないため）
- 巡回中は画面を点けたままにする
- 登録地点の CSV は端末の「ダウンロード/巡回ナビ」に直接保存（古い Android では共有メニューから保存先を選ぶ）
- 設定・登録地点はアプリ専用の場所に保存されるので、Chrome の履歴・サイトデータを消しても消えない
  （ブラウザ版の登録地点は引き継がれません。ブラウザ版で「CSVで保存」→ アプリで「CSVで読み込み」で移せます）

## インストール
1. スマホで https://github.com/syuu-hub/syuu-hub.github.io/releases/tag/junkai-navi-apk を開き、`junkai-navi.apk` をダウンロード
2. 「提供元不明のアプリ」のインストールを許可してインストール
3. はじめて開く時は通信できる場所で。位置情報の利用を許可してください

## 署名の鍵について
タクシーアナライザー・Gメーターと同じく、リポジトリの Secrets の鍵（`ANDROID_KEYSTORE_B64`・`ANDROID_KEY_PASS`）で署名します。
登録されていない時は、その回だけの鍵で署名します（次の APK を入れる時はアンインストールが必要になり、アプリ内のデータが消えます）。
